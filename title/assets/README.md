# Identidade do Playmuth

`playmuth-symbol.svg` é o símbolo próprio do projeto: um anel com um triângulo de "play", preenchido em par/ímpar (o círculo interno recorta o anel). `make_icon.py` o rasteriza em PNG RGB de 512 x 512, branco sobre fundo escuro, com antialiasing e sem dependências externas.

Desde a 1.52 o título não usa o nome nem o símbolo do Azimuth (marca da Almost There Games). O Playmuth é um projeto independente e não oficial, que roda o motor Azimuth no PS5.
