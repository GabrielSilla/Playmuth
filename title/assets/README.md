# Identidade do Playmuth

- `playmuth-icon.png`: ícone do título, 512 x 512 PNG RGB. O `make_icon.py` confere o formato e o copia para `sce_sys/icon0.png` a cada build.
- `playmuth-icon-source.png`: o mesmo ícone em 1254 x 1254, como foi gerado.
- `playmuth-banner.png` (na raiz do projeto): banner de 1280 x 640 para o README do repositório público.

Arte gerada pelo usuário com o GPT em 02/11/2026: um "P" ciano com linhas de velocidade, um triângulo de "play" e uma agulha de bússola, sobre fundo azul-marinho escuro. Desde a 1.52 o título não usa o nome nem o símbolo do Azimuth, marca da Almost There Games. O Playmuth é um projeto independente e não oficial, que roda o motor Azimuth no PS5.
